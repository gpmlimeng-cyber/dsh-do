# MODO 2.2.0-rc.54（原生组件对齐、伙伴抽屉与发现页）

这一版把轻松模式的几处界面统一到 App 原生组件，并重做了「添加伙伴」的抽屉。

## 伙伴页

- 「+」打开的抽屉改成接近满屏的高抽屉：顶部大卡「自己捏一个伙伴」，下面是从模板开始的行，每行带头像、名字和一句话。
- 已经有同名伙伴的模板显示灰色「已添加」且点不动；点「添加」进预填好的新建页，不直接建。
- 模板横滑区从页面顶部挪到伙伴列表之后，作为页面最后一块。
- 右上角「+」与消息页一致：40 的圆、20 的图标。

## 发现页

- 从 4 列小图标网格改成「全部功能」那套原生两列卡片：圆底图标 + 标题 + 一句说明，分组标题也换成原生样式。
- 共 15 格，定时任务不在此列（走「全部设置」）。
- 需要会话的任务、终端、技能三格在无会话时置灰，点一下仍会提示。

## 模板页

- 搜索框换成原生搜索胶囊（填充底、无描边、带清除键），分类换成原生筛选胶囊（选中实心）。

## 吉祥物

- 「五官」档位优先于情绪：选简约或圆点后眼睛形状固定，情绪只影响嘴和特效。
- 默认五官画白色眼白 + 深色瞳孔 + 高光，2D 下也能和「圆点」区分开；三张五官预览改为静态、各自展示自己的形态。
- 颜色选中只用主色描边 + 浅主色底，头像上不再盖对勾。

## 说明

- 轻松模式界面统一走 App 的色板、圆角、字体与图标代币，并加了守卫测试防止以后又漂回自绘。
