# MODO 2.2.1（轻松模式正式版）

这一版把轻松模式（IM 界面）收尾成一整套：消息、伙伴、发现、我，加上吉祥物、伙伴模板和「想多久再回」。专业模式不变。

## 界面

- 轻松模式四页：消息、伙伴、发现、我；首次进入会问用哪种界面，之后可在设置里切换。
- 消息页：平铺会话列表、置顶瓦片区、未读与状态（正在忙 / 等你确认）、返回键回到消息列表。
- 伙伴页：单列联系人列表，一行一个伙伴（头像、名字、一句话、状态、发消息）；点行进资料卡；底部是「从模板开始」的横滑推荐。
- 发现页：原生两列卡片，15 个入口，分六组；需要会话的入口在无会话时置灰并给出提示。
- 资料卡：更换形象、用回宿主照片、恢复默认、改名/角色/说明、记忆、权限、想多久再回、删除；点头像也能换形象。

## 伙伴模板

- 「+」打开高抽屉：自己捏一个、6 个推荐模板、查看全部模板。
- 模板库来自 [grok-bot-cn](https://github.com/junze-xu/grok-bot-cn)（MIT）：24 个可直接用，其余标「即将支持」；12 个分类可搜索、可看详情。
- 选模板只预填新建页，创建仍由你点完成；已有同名伙伴的模板显示「已添加」。

## 吉祥物

- 12 个角色：芽团、机团、幽团、果冻、圆团、星团、角团、饭团、芋团、橘团、梨团、芒团。
- 17 个预设色 + 跟随角色默认色，共 18 格；含 Miffan 六色（经典、抹茶、樱花、月光、海盐、墨玉）。
- 五官三档：默认（眼白 + 瞳孔 + 高光）、简约（竖胶囊）、圆点；2D / 3D 视图可切，默认 2D。
- 动作三档（活泼 / 安静 / 好奇）在五官页，和五官一样是卡片选项。
- 所有出现形象的地方都会动，整屏共用一个时钟；眼睛会跟着手指看、会眨眼、会轻微转头，带一点远近呼吸；系统开「减少动态效果」时全静止。
- 深色身体上的五官用白色；颜色格选中只靠描边和底色，不盖对勾。

## 想多久再回

- 资料卡新增四档：秒回 / 看情况（推荐）/ 多想想 / 深思熟虑，只影响这一只伙伴。
- 实际映射到模型的思考档位：秒回选最快的一档，看情况用模型默认，多想想和深思熟虑依次更深；模型不支持思考时这一行不显示。

## 说明

- 头像配置存本机，换设备不同步。
- 模板里的技能、例行程序、团队安装没有搬——我们的伙伴没有这些字段。
