# MODO 2.2.0-rc.46（轻松模式 · 第二轮）

这一版把轻松模式的列表与背景补齐，并修掉 Bot 聊天里发图片一直失败的问题。

## 轻松模式

- **消息列表不再分组**：去掉「置顶 / 对话 / 群聊」三段标题，Bot 和群聊混成一条按最近活跃排序的平铺列表，主 Bot 不再强制在前。
- **置顶**：长按行或瓦片选「置顶」，置顶项进顶部瓦片区（1 个居中大瓦片、2–3 个一行、更多横向滚动），头像带未读角标；状态存本地。
- **第二行显示最新消息**：取宿主下发的 `preview`，为空才回落到状态文案（等你确认 / 正在输入 / 角色）。
- **顶栏左键**：单聊页和群聊页在轻松模式下固定为「返回消息」，不再挂专业模式的会话抽屉。
- **底部 Tab**：去掉选中点及其占位；底栏与背景一体化——壁纸/渐变一直铺到屏幕最底，不再有实色底和分隔线。
- **背景与专业模式一致**：设了自定义壁纸时，轻松模式也用同一张（无壁纸时是同一个渐变）。
- **伙伴页**：修掉列宽算错导致的「一列贴左、右边空着」，现在一屏两列。

## 修掉的问题

- **Bot 聊天里发图片失败**（提示「没能完成操作」）：宿主 `send` 只认先经 `stage-image` 暂存拿到的图片 id，客户端却直接把图片数据塞进 `send`，被宿主判成「照片没到」。现在客户端先把每张图暂存换 id 再发，一次一张、发送成功即失效。
- 客户端包 `dsbot_api_test` 里两处过期断言（`api` 版本还写 `[1]`，实际是 `[1, 2]`）。

## 说明

- 群聊仍未轻量化：消息列表里点开群，进的是现有群页。
- 新文案仍放在本地双语表（`app/lib/ui/im/im_strings.dart`、`im_face_settings` 同目录），等能跑 `flutter gen-l10n` 时统一迁到 `lib/l10n/parts/*.arb`。
- 这条开发分支上有一份临时的 CI 流水线文件（`.github/workflows/im-branch-ci.yml`），合并回 rc 线前会删掉。
