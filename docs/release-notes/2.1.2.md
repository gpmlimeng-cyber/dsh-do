## MODO 2.1.2

基于上游 **dsh-go v1.0.10**（作者 ccch1mneyyy）的修改版。本版集中在群聊体验：状态行、消息筛选、详情页与显示反馈。改动记录见 `design/app-source-changes.md`。

### 新功能

- **群聊消息模式**：输入框右侧新增入口（详情键左边），可切换「全部 / 仅与我相关 / 按成员」。「按成员」只看该成员在本群的发言（不是它的私聊）；「仅与我相关」减少成员之间互相派活的噪音。模式按群记住，默认全部。
- **输入区状态行**：运行中显示「头像 + 名字 + 动作 + 工具目标 + 计时」，多人并行只留一位并显示「+2」，长按 4 秒看 tok/s；成员完成时短暂提示「某人 已完成」；待批准整行警示色。忙时插件胶囊行整段让位，空闲才出现。
- **上下文环**：输入框右侧显示群合计上下文占用，点击直达「对话详情 → 上下文」。
- **完成后提示**：成员交完活不再在消息流里留一行「已完成」，改在顶部状态行提示 6 秒；只回 PASS 或没文字时仍保留那行。
- **详情页页签吸顶**：群「对话详情」滚到页签后页签冻结，内容在页签下继续滚，和单聊一致。
- **上下文页简化**：只留「上下文 → 本对话 → 每轮用量」，成员合计与成员明细移除；合计数据仍按群会话 + 各成员在本群的会话计算。

### 缺陷修复

- **发图没有即时反馈**：图片发送后先出现本地缩略图的「排队中」气泡，宿主写入日志后原地替换；失败时气泡收回、草稿留在输入框。
- **交付物卡片重复**：同一份文件只出一张卡；只挂本轮（最后一条用户消息之后）说过话的成员，翻历史页不再出现旧卡。
- **抽屉高亮**：从 Bot/群会话返回抽屉时，当前会话行会被选中。
- **状态重复**：顶部不再重复「谁在跑」，只留四种状态（待批准 / 讨论中 / 已暂停 / N 位成员）加「已说 N」；具体动作只在底部一行。

### 已知问题

- 页签吸顶条的固定高度按 60dp 取；大字体下若被裁或留白，调这一个常量即可。
- 抽屉高亮在「Bot 页压在栈里、再开普通会话」的极端路径下可能残留，已按「抽屉 → 普通会话 → 再开抽屉」列入验收。
- 「仅与我相关」是近似规则：群日志没有回合/回复关系字段，按「你发言之后、下一条发言之前、未 @ 其他成员」判定；精确版要等插件在日志行补 `replyTo`/`round`。
- 成员本轮只说话、没有产出时，仍可能挂着它上一轮的交付物卡。
- `app/lib/l10n/gen/` 三份生成物仍是手写，CI 构建会重新生成、不影响包内容；待有 Flutter 的环境再归位。
- 开启毛玻璃时抽屉顶部亮带（上游皮肤问题，未变）。
