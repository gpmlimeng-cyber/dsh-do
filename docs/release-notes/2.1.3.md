## MODO 2.1.3

基于上游 **dsh-go v1.0.10**（作者 ccch1mneyyy）的修改版。本版修 2.1.2 反馈出来的三处问题：抽屉会不会把会话弹掉、抽屉高亮选哪一行、上下文环把「没测到」画成 0%。改动记录见 `design/app-source-changes.md`。

### 缺陷修复

- **开抽屉会把当前会话弹掉**：从 Bot 或群聊点头像键打开抽屉时，页面先被弹回 shell 再开抽屉，当前会话随之销毁——未发送的草稿、滚动位置、展开的卡片一起丢。现在 Bot 页和群页自带抽屉：开抽屉只是盖在会话上，返回键先关抽屉、再按一次才回 shell；头像键和边缘拖动两个入口行为一致。
- **抽屉高亮选错行**：上一处修好后，抽屉在 Bot/群页里只亮当前那个 Bot 或群；进入 Bot/群会话后，原生会话行不再保持选中。在抽屉里选原生会话、选另一个 Bot、新建对话都在同一个抽屉里完成跳转，返回栈不会叠两层 Bot 页。
- **上下文环把「没测到」画成 0%**：上下文压力还没测出来时，环显示 0%，看起来像「没用上下文」，实际是未知；成员一跑起来又跳到 6%，同一个指示器在说两种话。现在缺失或为 0 一律按未知处理，环不显示；成员合计、成员行与每轮用量同一口径。

### 变更

- 抽屉的控制器、拖动识别与遮罩提取为 shell 和 Bot/群页共用的 `SessionDrawerHost`，动画和手势只有一份实现，不再各写一套。
- 移除「页面请求 shell 开抽屉」的旧通道（`openDrawerOverShell`、`drawerOpenRequestProvider`）。

### 已知问题

- 在抽屉里选原生会话、新建对话或切换到另一个 Bot 时，当前 Bot 页仍会被关掉，未发送的草稿与滚动位置随之丢失（与按返回键一致）。按 botId 保存草稿属于后续工作。
- 页签吸顶条的固定高度按 60dp 取；大字体下若被裁或留白，调这一个常量即可。
- 「仅与我相关」仍是近似规则：群日志没有回合/回复关系字段，按「你发言之后、下一条发言之前、未 @ 其他成员」判定。
- 上下文合计只把有实测值的会话计入窗口：全员都在群、只有部分成员测到时，百分比会偏大（环、合计卡、每轮用量三处对齐即可）。
- 开启毛玻璃时抽屉顶部亮带（上游皮肤问题，未变）。
