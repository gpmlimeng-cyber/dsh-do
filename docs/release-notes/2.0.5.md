## MODO 2.0.5

基于上游 v1.0.8。

### 缺陷修复
- **群聊顶栏不再重复说话人**：此前会显示成「Chief 正在发言 · 已说 3 · 测试 正在发言」，两处来源还不一致；现在顶栏只说「已说 N」，谁在发言交给状态行。
- **带文件的消息不再重复**：主机把文件写成一行 `[File "名称" (N 字节) attached]` 塞进正文，手机上文件已经单独画成卡片，这行现在不再显示；只发了文件的消息气泡直接不出现。
- **消息里的文件卡片可以打开**：文件引用现在同时认 `id` 与 `attachmentId` 两种字段名，点了能读出内容；确实取不到引用时会明说打不开，而不是毫无反应。

### 已知问题
- 交付物（`present`）卡片在 Bot 对话页仍不渲染，正文里只有一个点了没反应的 markdown 链接；排查中，计划 2.0.6 修。
- 开启毛玻璃时，抽屉顶部两个圆钮会透出一条横向亮带（上游皮肤问题，关闭毛玻璃即消失）。
