# MODO 2.2.0-rc.49（吉祥物保真第一版）

这一版把「芽团」按 lively-mascot 引擎的原始数值重画，并加了一个可以逐格对照的表情墙。

## 芽团（sprout）保真

- **身体**：圆角 50% 50% 46% 49% 的椭圆角；3D 明暗按引擎参数——径向高光在 25%,18%、145° 白光、325° 暗边、底部内阴影。
- **脸**：眼睛在 (34,43)/(66,43)，眼白 20×23 带 2.4 描边，瞳孔 r6.2 加两颗高光（2.1 / 1.0），腮红 (20,57)/(80,57)；嘴用引擎的 5 条路径。
- **顶饰与脚**：叶子 37×40 挂在身体上沿，茎/左右叶/叶脉/高光按原路径；脚是两个深色椭圆。
- **描边**：按「不要边框」的要求，身体不画外描边；五官和装饰的线条保留，否则脸看不清。

## 表情墙

- 设置 → 关于 → 版本号连点 7 下（2 秒内）进入：5 角色 × 40 情绪的静态格子，带情绪 id。
- 全部静态帧，不跑动画，用来和官方 demo 逐格对照。

## 说明

- 其余四个角色（猫团 / 机器团 / 幽团 / 果冻团）目前仍是近似画法，等芽团确认后再套。
- `effect`（星星、爱心、加载环、睡眠泡泡）配方已有、尚未绘制，仍在欠账里。
