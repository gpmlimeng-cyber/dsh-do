## MODO 2.1.0

基于上游 **dsh-go v1.0.10**（作者 ccch1mneyyy，https://github.com/ccch1mneyyy/dsh-go）。
本版是一次基线升级：把上游 v1.0.8 → v1.0.10 的 181 个提交并入，我们的功能全部保留。

### 新功能（来自上游）
- **动效一套重做**：弹簧按压、sheet 手势延续速度、思考文案慢速扫光与交接、发送图标过渡、动画开关覆盖到页面与弹层。
- **手机操控修复**：能力探测、失败定位、树连接关闭、输入回执校验、PRoot 启动错误分类等 30 处。
- **远程**：主机详情快捷入口与工作区文件上传。
- 对话：引擎图片跟随连接、待办滚动保持、toast 与输入框时序、compact 超时。
- 设置：显示原作者与个人主页链接。

### 保留的本项目功能
- DS Bot 原生客户端：团队页、Bot 对话、群聊、群「对话详情」（轨迹/改动/文件/进度/上下文）、交付物卡片、正文文件链接可点。
- DS Bot 插件更新入口（每日自动 / 热启动补查 / 手动）。
- MODO 品牌、图标与更新源；上游版权、许可与修改声明见仓库 NOTICE 与 LICENSE。

### 已知问题
- 开启毛玻璃时，抽屉顶部两个圆钮会透出一条横向亮带（上游皮肤问题）。
- 「新建群聊按群名自动建群空间目录」仍未做，需要插件新增端点。
