## MODO 2.0.6

基于上游 v1.0.8。

### 新功能
- **群活动面板**：群详情里多一行「活动」，按成员列出本轮次、上下文占用和出字速度，底部是成员数、总轮次、缓存命中率与最接近满窗的成员。数据来自每个成员会话已有的统计，不用改插件。
- **DS Bot 插件自己的更新**：团队页底部新增 DS Bot 卡片，显示已装版本与 fork 上的最新版本（有新版本 / 已是最新 / 暂时检查不了），点「更新」即可换装。检查每天自动一次、回到前台超过 12 小时补一次，也可随时手动点。

### 缺陷修复
- 文件卡片打不开的问题定位到插件侧（读取时缺少字节数、被判为校验失败），已在 ds-bot 0.2.6 修复；手机端更新插件后生效。

### 已知问题
- 交付物（`present`）卡片在 Bot 对话页仍不渲染，正文里只有一个点了没反应的 markdown 链接；计划 2.0.7 修。
- 开启毛玻璃时，抽屉顶部两个圆钮会透出一条横向亮带（上游皮肤问题）。
