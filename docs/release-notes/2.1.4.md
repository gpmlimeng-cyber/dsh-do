## MODO 2.1.4

基于上游 **dsh-go v1.0.10**（作者 ccch1mneyyy）的修改版。本版集中在群聊：成员会话切换、详情页吸顶、消息列表置顶与交付卡去重。

### 新功能

- **成员会话切换**：群聊页标题变成「群聊按钮」，点它回群聊；「消息模式」面板上半是切换会话（群聊 / 各成员），下半是过滤开关。点成员进入该成员在本群的会话，显示「我发的 + 该成员的发言」，输入框上方常驻「发送到群聊，群里都看得见」。任何路径都不打开私聊。
- **消息列表置顶**：Bot 行和群行长按出动作面板（置顶 / 取消置顶 / 移到文件夹）。一个置顶块内先原生置顶会话、再 Bot 与群行；本地保存，冷启动和升级后都在。
- **详情页吸顶**：群「对话详情」改用和单聊同一套联动滚动，轨迹 / 改动 / 文件 / 进度 / 上下文五个页签真正冻在顶部；页签条高度统一为 52。
- **消息模式按钮**显示当前会话（群聊图标 / 成员头像 + 主色环），过滤生效时右下角一个小点。

### 缺陷修复

- **开抽屉把会话弹掉**（2.1.3 遗留）：Bot/群页自带抽屉，开抽屉不再退出会话；返回键先关抽屉、再按才回列表。
- **抽屉高亮选错行**：进入 Bot/群会话后只亮当前那一行，原生会话行不再残留选中。
- **交付物卡片重复**：群 relay 会话不再把成员已交付的同一批文件再出一张卡。
- **上下文环**：成员行、合计窗口、每轮用量统一成「缺失或 0 即未知」，不再把没测到画成 0%。
- **成员详情**：详情按钮打开该成员在本群的会话详情，不聚合、不回退私聊，顶部标「只看 <成员> · 本群」。
- **预览版开关**：打开「包含预览版」现在真的会去查 releases 列表，能看到预览版。

### 已知问题

- rc.1 里预览版开关仍不可用（修复在 rc.2 起）；rc.1 因此看不到后续预览版。
- 在抽屉里选原生会话、新建对话或切换到另一个 Bot 时，当前 Bot 页会被关掉，未发送的草稿与滚动位置随之丢失（与按返回键一致）。
- 页签吸顶条固定 52；大字号下可能偏矮。
- 「仅与我相关」仍是近似规则：群日志没有回合/回复关系字段。
