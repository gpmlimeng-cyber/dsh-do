## MODO 2.0.7

基于上游 v1.0.8。这一版重点补齐群聊的「对话详情」，并修好交付物卡片。

### 新功能
- **群聊右上角打开「对话详情」**：和单聊同一套五页签，但数字按**全部成员在本群的会话**汇总（合计 = 成员 + 群会话）。
  - 轨迹：顶部每位成员的轮次、工具调用数、用时，下面照旧是群会话的逐轮轨迹。
  - 改动：按成员分块列出各自改过的文件（同一文件被两人改就分两行），点开看 diff。
  - 文件：群有统一目录时直接看群目录；各自目录时底部一条筛选条（管理员 → 其他成员 → 群），默认停管理员，点谁看谁的目录。
  - 进度：本群当前状态（暂停/谁在跑/谁等审批）+ 每个成员的未完成待办与完成进度 + 群会话自己的目标与待办。
  - 上下文：群会话用量摘要 + 成员合计（最大上下文占比、token 合计、缓存命中、出字速度）+ 成员明细 + 最近轮次用量条。
- **DS Bot 插件更新入口**：团队页底部显示已装版本与 fork 最新版本，可手动检查、每日自动检查、回到前台超过 12 小时补查。

### 缺陷修复
- **交付物卡片**：Bot 对话页现在会显示每个回合交付的文件卡（此前只有正文里的链接）；群聊页也按成员显示各自的交付物。
- **正文里的文件链接可点**：`[名字](路径)` 按会话工作目录解析后打开预览，不再点了没反应。
- **文件卡片可打开**：配合 ds-bot 0.2.7（插件侧读文件兜底），点卡片能读出文件内容。
