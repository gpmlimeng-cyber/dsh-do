# MODO 2.2.0-rc.52（伙伴页改版、编辑形象与模板库）

这一版把「伙伴」页从卡片网格改成联系人列表，资料卡可以直接换形象，并接入了一批现成的伙伴模板。

## 伙伴页

- 一行一个伙伴：头像 56、名字、一句话（角色）、右侧状态，头像右下角是状态点，右上角是未读数；行尾「发消息」直接进对话。
- 点整行进资料卡（不再是点一下直接进对话）。
- 状态只做两态：「正在忙」「等你确认」，等你确认优先；列表是静态帧，不跑循环动画。
- 0 个伙伴时给「创建 Bot」主按钮和一个「从模板开始」文字按钮。

## 资料卡与形象

- 新增「更换形象」：进现有的吉祥物自定义页，角色 / 颜色 / 五官 / 动作 + 字团都在里面。
- 宿主有照片时可以「用回宿主照片」；已经配置过形象的，多一行「恢复默认形象」。
- 点大头像也能进换形象页；头像统一 112。
- 改名 / 角色 / 说明失败（撞名、空名、超长）现在会弹提示，不再是无反应的异常。

## 伙伴模板

- 伙伴页右上「+」和空态都能进模板：「自己做」、6 个推荐、全部模板。
- 全部模板页：12 个分类 + 搜索 + 详情；点「用这个模板创建」进新建页，名字 / 角色 / 说明 / 形象已预填，创建仍由你点完成。
- 模板来源 [grok-bot-cn](https://github.com/junze-xu/grok-bot-cn)（MIT）：目前 24 个可直接用，其余标「即将支持」。
- 模板只搬「任务 + 边界 + 工作方式」，没有搬它的技能、例行程序和团队安装。

## 吉祥物

- 五官三档（默认 / 简约 / 圆点）现在对全部 14 个角色生效；之前只有芽团会变。
- 圆团改成正圆；角团整体上移，视觉重心落在画布中央。
