## Coka 2.1.9（预览版）

这一版加的是**群任务板**：群里除了「目标」，现在还能有一张可以随手加、随手勾的任务清单；群目标和它的任务共用同一张清单显示。另外把群目标的展示重新做了一遍。

### 更新前请注意

- 这是预览版，不是正式版。App 内要在 `设置 › 更新` 里打开「包含预览版」才看得到。
- 直接覆盖 2.1.8 就行，包名没变。
- 群任务需要引擎侧的新版本插件（宿主 `dsh-bot`），旧引擎上任务条不会出现，不报错。

### 群任务板

- **一张清单**：输入框上方一条「2/5 · 正在：写验收标准」，点一下在原地展开，不弹页、不跳走。
- **两种来源**：自己随手加的一条，和群目标推进时自动同步进来的阶段任务（后者带「目标」标签、不能手动改状态）。
- **六个状态**：未开始 / 已领取 / 进行中 / 已完成 / 失败 / 已取消。取消留痕，不删除。
- **负责人**：可以指派给群里任何一个成员，也可以空着（显示「未指派」）。
- **前置依赖**：一条任务可以等另一条。前置没完成时它显示「等 3 号」、点开始会被拦下并说清差哪条；前置完成自动解锁成「可开工」。取消一条前置**不再**挡住后面的——取消的意思是这件事不做了，等它的活照样能开工。
- **质量门（可选）**：手动任务可以选择走「需求→实现→验证→评审」，评审不过会自动生成修复任务再评一轮。
- **改派保护**：任务改派给别人后，原来那位迟到的「我做完了」会被拒绝，不会覆盖新结果。
- **任务图**：清单右下角切到图，节点按依赖从左往右排、曲线连前置，点一下亮上下游、再点一下打开任务面板。打开时自动缩到能看全，双指缩放、手指拖是平移。
- **就绪提醒**：每次群回合开始前，管理员会看到「这几条已经可以开工」，顺手把人叫起来，不用你盯。

### 群目标的展示重做

- **输入框上方那条**改成和任务条同一副骨架：折叠时一条「第 2/4 段 · 这一段的名字」，点开原地展开。
- 展开后是阶段圆点、这一步的完成标准、每个成员这一步的任务和状态、目标与验收，底下一行暂停/停止。
- **对话详情的「进度」页签**也换成目标进度：目标一张卡、每一步一张卡，点开同一个面板。
- 群任务也会列在这一页，点开任务面板。

### 这一版修掉的问题

- **「等 N 号」会显示成乱码串**：任务模型没有解析群内编号，之前拿 id 后五位凑，现在直接用服务端给的编号，删一条也不会串号。
