# MODO 2.2.0-rc.53（2D / 3D 视图，全员动画）

这一版给吉祥物加了 2D / 3D 视图开关（默认 2D），并让所有出现形象的地方都动起来，整屏共用同一个时钟。

## 视图 2D / 3D

- 五官页顶部新增「视图 2D / 3D」两段选择，默认 **2D**，切完预览当帧就变。
- 2D：纯色身体，没有渐变、内阴影和左上高光，眼白高光也去掉，像贴纸。
- 3D：保留原来的渐变、内阴影和高光。
- 字形头像（字团）同样吃这个开关：身体扁平或立体，字色按明度算，不受影响。
- 存档只写 `view`，存过 `three` 的老存档仍是 3D；没有这个键的老存档落到 2D。

## 动画

- 伙伴页行头像、消息列表头像、置顶瓦片、新建页预览、自定义页预览、资料卡、聊天头，全部会动。
- 一屏多个头像共用一个时钟：只有一个 ticker，头像按 `CustomPainter` 重画，不再各自起控制器；页面被盖住时自动停。
- 系统开启「减少动态效果」时一律静止，一帧都不跑。

## 说明

- 2D 是默认视图，因此没有单独配过头像的 Bot 会比上一版看起来更扁。
