# MODO 2.2.0-rc.47（轻松模式 · 第三轮）

这一版让图片消息真的显示出来，并把置顶区改成 Miffan 那样的自适应网格。

## 图片消息

- **消息里的图片会显示**：宿主其实一直在消息里给出图片的 `imageRefs`（附件 id、类型、名字），App 之前没解析、也没取图，所以只显示「图片」占位。现在按附件 id 通过 `image` 端点取 512px 预览画在气泡里，点开看原图。
- **专业模式和轻松模式共用同一个气泡**，两边一起生效。
- 取图走进程内缓存（64MB / 200 张，同一张并发只取一次，换主机清空），失败只显示坏图标，点一下才重试。
- 老宿主没有 `imageRefs` 时保持原来的「图片」占位。

## 置顶区

- 按 Miffan 的排法：**1 个**居中大瓦片；**2–3 个**一行均分；**4 个以上**一行最多 4 个、均分，溢出换行，尺寸固定不变（不再横向滚动）。
