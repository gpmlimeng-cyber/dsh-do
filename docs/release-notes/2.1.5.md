## MODO 2.1.5

基于上游 **dsh-go v1.0.10**（作者 ccch1mneyyy）的修改版。本版三件事：记住上次会话、接上多屏布局、把新建入口收成一个面板；语音输入的判定链路也一并修了。

### 新功能

- **记住上次会话**：退出前停在哪个会话，冷启动就回到哪个——原生会话、Bot、群聊，以及群里的某个成员会话都记。对象被删、Bot 被移除、成员被移出群时分别回落，绝不拿「第一个会话」顶替；恢复前不先闪一个错的会话。
- **多屏适配**：接上游同一套断点（<600 / 600–840 / ≥840，高<480 视为手机）。≥840 时左列表常驻、右侧详情面板，详情键变成显隐开关；600–840 详情走宽 sheet；手机布局不变。
- **新建面板**：侧栏顶部按钮改成「新建」，点开是一个面板——原生新会话、最近打开的会话、新建 Bot / 群 / 分组，顶部输入框可按名字搜；新建分组就地命名；输入框里写了名字可直接新建同名 Bot。会话列表选项里原来的新建 Bot / 群 / 文件夹三行随之移除。
- **侧栏更新提醒**：抽屉底部多一行，有更新才出现、没有时零占位；一行承载「有新版本 / 正在下载 / 可安装」三种状态，点它直接打开更新弹窗。
- **排队消息与上游对齐**：Bot 和群聊发出的消息进的是和原生会话同一条队列。还在排队的显示「排队中 · 本轮结束后发送」，插进来的显示「插话 · 下一步生效」，动作是「立即发送 / 改为插话 / 撤回」，和原生会话那套完全一致；Host 没带队列信息时退回原来的待发气泡，不给点不动的按钮。
- **翻看记录时不再被顶走**：上滑离开底部超过一屏后，消息流冻住不动——成员继续输出、新消息继续来，位置都不动，只在回到底部的按钮上累计条数，点它才回到最新。

### 缺陷修复

- **语音模型被误判**：模型还在准备（`checking`）时被当成「没有模型」，于是退到系统识别并报「无法启动系统识别」。现在准备中会等它就绪，不再退系统。
- **语音模型文件丢失**：文件被删空后设置页仍显示「已就绪」。现在状态以引擎探测为准，文件不在会明说「本地模型文件不在了」并给重新下载。
- **删掉本地模型会连累云端**：以前删模型会把语音插件一起关掉，云端识别也跟着挂。现在两者解耦，删模型不影响云端。
- **引擎没加载语音插件**：单独一种状态，给「重启引擎」的入口，不再和「模型缺失」混在一起。
- **发出去的消息只能靠猜**：以前靠「文本 + 附件数」去认自己的回显，图片和重复文字经常认错，表现为一条消息卡在待发、或者凭空多出一条。现在每条发出的消息带客户端身份，回显按身份精确认领；重试带同一个身份，不会重复落库。
- **待发气泡有三种状态**：发送中（气泡半透明）、超过 8 秒改成「还在等服务器确认」、20 秒没回显标「没能发送」并回到不透明。失败时给「重试」和「撤回」两个动作，撤回才把文字放回输入框。
- **计数徽标撑变形**：超过 99 显示「99+」，不再把胶囊拉成一条。

### 已知问题

- **排队标签暂未生效**：Bot 和群聊的队列已经接上 Host（消息确实按顺序排队，不会丢），但「排队中 · 本轮结束后发送 / 插话 · 下一步生效」这两个标签和随之出现的三个动作还没打通，气泡仍显示「发送中」。发送本身不受影响；修好之前不显示任何排队按钮，不会出现点不动的东西。
- 云端语音识别、长按说话（上滑取消）、工作区 HTML 文件的应用内预览、群文件根目录的虚拟层，都排在这一版之后。
- 大字号下的若干弹层高度还需要真机确认。
