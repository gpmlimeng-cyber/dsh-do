## MODO 2.1.1

基于上游 **dsh-go v1.0.10**（作者 ccch1mneyyy，https://github.com/ccch1mneyyy/dsh-go）的修改版。本版是 2.1.0 的缺陷修复与界面补齐，共 12 个提交（9 个改 App 源码 + 3 个台账），改动记录见 `design/app-source-changes.md`。

### 缺陷修复

- **侧栏群聊重复行**：群换过分片后，它当前跑的那场会话不在隐藏集合里，于是与群行并排出现；现在把群当前分片也收进隐藏集合。
- **抽屉搜索键**：2.1.0 合并上游时被药丸形搜索条覆盖，恢复为 36dp 玻璃圆键，与「网页模式」「新对话」同一套。
- **群「对话详情」标题**：改为「对话详情」，群名保留在 hero 区，与单聊面板一致。
- **消息执行后仍显示「排队中」**：本地待发消息与回显按整段文字配对，图片识读注记让配不上；现在配对前先剥离注记（老主机也兜得住）。
- **轨迹页成员 chip**：换群、成员被移出、或成员在本群解析不到时，都回落到群聊，不再出现「无选中 chip + 空态」。

### 界面与数据

- **上下文合计**：群「对话详情 › 上下文」顶部两张卡改为「群会话 + 各成员在本群的会话」合计；上下文按总占用 ÷ 总容量；全 0 时不画卡；成员明细保留。
- **每轮用量**抽成公共组件，单聊上下文页与群聚合页共用，统一等宽数字。
- **群输入区**新增状态行（有人跑时显示「谁在做什么 + 计时」，空闲零高）、上下文环（群合计，点击进「对话详情 › 上下文」）、运行中麦克风（运行中 + 输入为空 + 语音可用时出现）。
- **消息长按菜单对齐原生**：Bot 气泡为「复制 → 选择文字 → 引用 → 分享」（预览、复制、分享走纯文本，不再带出 `dsh-ui` 的 JSON）；用户气泡为「复制 → 选择文字 → 引用」（去掉分享，预览打码）。
- **轨迹页**：顶部改为「群聊 + 成员」横向标签，点谁看谁的轨迹。

### 已知问题

- 顶部合计百分比（总占用 ÷ 总容量）与下方成员明细的「最满成员」口径不同，两组数字对不上属预期。
- 图片识读注记仍会显示在消息正文（ds-bot 0.2.9 尚未发）；「排队中」卡住已由 App 侧兜底解决。
- 抽屉里若在成员于群里发言后多出成员会话行，属同类第二处，待真机确认后补一行。
- 上下文环内部重复计算、成员明细与合计口径不一致，记入待办。
- 开启毛玻璃时抽屉顶部亮带（上游皮肤问题，未变）。
