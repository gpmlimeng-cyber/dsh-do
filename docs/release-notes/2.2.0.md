# MODO 2.2.0（群目标移植）

这一版把网页端的群目标搬进手机原生界面，并修掉它一直不显示的根因。

## 群目标

- **顶栏一颗胶囊**：群名在有目标时换成目标胶囊——收起态是「进度环 + 标题」（设置里可切「简单/完整」两种显示），点开是面板。
- **面板照网页端对齐**：状态与正文（起草态显示 brief，与标题同值时不重复）、阶段步进器（起草态不画）、当前阶段的完成标准与打回记录与证据、成员任务行、可折叠的「目标与验收」、底部动作区。
- **动作与网页端一一对应**：进行中「暂停」「停止」，已暂停「恢复」「停止」，完成或停止后「清除」，起草中「取消」；停止要连点两下（3 秒内）才算数，确认写在按钮里，不弹提示条。
- **已暂停但还有人在跑**时，多一颗「连当前工作一起停」——它只停工作，目标保持暂停。

## 修掉的问题

- **目标一直不显示**的根因不在手机端：Host 的路由表把 `goal-view` 漏在只读白名单里、没接进分发，读请求全被判成「未知端点」。补上分发后，胶囊立刻出现。这是 Host 侧一行代码，**不需要重装 App 才能修**，但需要重启引擎。
- 面板正文不再重复顶栏的标题。
- 稍后读屏不再把标题念两遍（整行做成一个带标签的按钮）。
- 收起面板后不再抢焦点、不再自动弹键盘。

## 说明

- 本版为预览版，供装机验证；阶段推进仍只能由管理员在群里做，手机上不提供「通过本阶段」。
- 加号菜单的内容与位置这一版没有动。

## rc.9 追加

- **群目标面板改成浮动卡**，照「手机控制」那张浮窗的版式：左右留边、圆角 24、头部 48 高，**暂停/停止搬到卡片头部**，底部只留「取消/清除」文字链；不再铺遮罩，点卡外收起。
- **起草态正文不再显示那句「要完成什么」**：标题已经在卡片头部，brief 与标题同值时正文留空。
- **消息范围改成两档**：「全部」与「只看某位成员」；「仅与我相关」下线（它是靠猜的）；过滤生效时顶栏一颗「只看 某人 ×」，不过滤时零占位；不再跨启动记住。

## rc.10 追补

- 消息范围过滤时**保留用户自己的消息**：过滤只影响渲染，刚发出的那句不会立刻消失（与成员会话页同一套规则）。
- 过滤后的空态改为「这一段里没有他的发言」——客户端只看得到当前这一段，不再说成「本群还没说过」。
- 起草态的目标卡片不再空着，正文给一句「起草中，等管理员开始」。

## rc.11 追补

- 过滤后「这一段里没有他的发言」改成**列表里的一条提示**，不再靠整屏空态：列表里只有我自己的消息时也看得到。
- 顶栏最右那颗「详情」换成 **⋯ 菜单**：对话详情 / 消息范围 / 成员，三项；详情不再单独占一颗键。长按 ⋯ 仍直接进对话详情。
- 修掉「完整显示模式下群名被压成一条竖杠」：目标胶囊改成弹性子项，长标题先省略胶囊文字。

## rc.12 追补

- **顶栏改成两态**：默认小球（44 圆、环 32），点开是完整胶囊；窄屏时胶囊横向撑满、群名缩成圆头像，宽屏时群名与胶囊都完整。**删掉设置里的「群目标显示」**——形态改由小球/胶囊与宽度决定。
- 完整胶囊改成胶囊形圆角（stadium），与群名胶囊同一套。
- 面板里加「收起成小球」；目标暂停时收起态带暂停图标。
- 面板头部的暂停/停止换成手机控制浮窗那套按钮，停止红色；停止仍是两段式。
- 面板里的成员任务行改成**头像 + 名字 + 行尾状态**，名字用标准正文色，不随状态染色。
- 阶段步进器节点之间加连接线（间距 28、线高 1.5、已完成段用成功色），数字 11→12。
- 过滤后「这一段里没有他的发言」作为列表里的一条提示，不再靠整屏空态。
- 顶栏最右「详情」换成 **⋯ 菜单**：对话详情 / 消息范围 / 成员。

## rc.13 追补

- 面板里的「目标与验收」挪到最底部、默认折叠；展开后内容往下长，折叠时不占高度，顶部不再重复显示目标与验收。
- 面板底部那行照网页端排：**左边「目标与验收」折叠钮，右边暂停/停止**；头部只留标题与收起箭头；展开的验收内容在这一行下面往下长。

## rc.14 追补

- 「收起成小球」放到**面板顶部右侧**，做成圆形按钮（36 圆盘 / 48 触控 / tonal 底 / 18 图标），与抽屉、⋯ 同一套圆键；点了收回小球并关面板，底部不再放这一项。

## rc.15 追补

- 面板正文最上面加**简版摘要**：`目标` 与 `验收方法` 各最多两行截断，空则不画；完整内容仍在底部折叠里。
- 目标相关文案统一改用网页端措辞：验收方法、完成标准：…、目标与验收、回到当前阶段、X 打回重做、X 已打回 n 次、确认终止？、清除。
