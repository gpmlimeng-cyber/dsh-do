# MODO 2.2.0-rc.48（吉祥物与新建伙伴页）

这一版给每个 Bot 长出脸：原生重绘的吉祥物头像、跟着会话状态变的 40 种表情，以及照 Miffan 重做的新建伙伴页。

## 吉祥物头像

- **5 个角色**（芽团 / 猫团 / 机器团 / 幽团 / 果冻团）× **3 种五官**（温和 / 机灵 / 呆萌）× **6 种预设色**（经典 / 抹茶 / 樱花 / 月光 / 海盐 / 墨玉）× **3 种动作等级**（活泼 / 安静 / 好奇），全部 Flutter 原生绘制：3D 渐变、无描边，不依赖 WebView。
- 头像下方一行标签 `角色 · 颜色 · 动作`，跟随选择实时变化。
- 文字头像保留；老 Bot 没配置吉祥物时照旧显示原来的文字头像。
- 外观配置存在本机（换设备不同步），六种预设色同时映射到宿主认可的颜色名，保证其他端底色正常。

## 表情跟着状态走

- 用 `lively-mascot` 的 40 个情绪做底：断线、启动、重连、等你确认、出错、暂停、搜索、改文件、说话、思考、旁听、刚完成、未读、空闲、久闲呼吸。
- 优先级高到低：连接态 → 等你确认 → 出错 → 暂停 → 正在做 → 旁听 → 刚完成（1.5 秒）→ 未读 → 空闲。
- 状态一变立刻换表情，不排队；只有「刚完成」是 1.5 秒瞬时，其余由状态本身维持。
- **列表/置顶瓦片只画静态一帧**，聊天页顶部和资料卡才播动画——几十个头像同时动会掉帧。

## 新建伙伴页

- 照 Miffan 重排：顶部大预览 + 三段标签 + 「换个样子 / 随机换一个」→ 名字（必填）→ 一句话它是做什么的 → 性格八选（不预选）→ 补充说明 → 模型（仅专业模式）→ 完成。
- 「随机换一个」：角色和颜色必换、五官保持、动作随机，种子可复现。
- 性格标签拼进说明（不新增宿主字段）。

## 说明

- 头像配置只在本机生效；要在多设备同步需要宿主先有存放位。
- 表情的「特效」（星光、加载环等）暂时只画了笑眼的星光，其余留给后续。
- 群聊叠加头像目前只画整体情绪，还没有逐个成员分别画。
