## MODO 2.0.3

基于上游 v1.0.8。

### 新功能
- **群级权限（全员统一）**：群设置里可以给整个群指定一个权限预设，取代每个成员自己的预设。切换会立刻改到本群所有成员的现有会话，不只是下一轮；关掉即回到各用各的。
- **停全部**：群详情里一次停掉所有正在工作的成员。
- **成员行显示「等待你审批」**：有成员停在等你批准时，行上直接标出，优先级高于「工作中」。
- **排队消息显示等待时长**：排队中的消息标出「已等 X 分 Y 秒」。
- **回到底部的新内容角标**：离开底部期间新到几条，按钮上直接显示，滚回底部或点它清零。
- **本轮发言进度**：群聊顶部显示「已说 N · 正在说 谁」，随回合实时更新。

### 缺陷修复
- 修复 `DsBotRoom` 缺少权限字段导致的编译失败。
- 群聊详情页的权限说明与只读状态处理。

### 已知问题
- 长按桌面图标的快捷方式仍指向旧包名，暂不可用。
- 开启毛玻璃时，抽屉顶部两个圆钮会透出一条横向亮带，关闭毛玻璃即消失（上游皮肤，待查）。
