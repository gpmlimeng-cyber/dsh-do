# MODO 2.2.0-rc.45（轻松模式）

这一版把「轻松聊天」做成与专业模式并存的第二套界面：像 IM 一样和 Bot 说话，专业功能一个不少。

## 两套界面

- **默认仍进专业模式**，老用户和升级用户的行为不变。
- 切换入口：设置 → 界面 → 聊天界面（专业 / 轻松），也可以在「我 → 高级」里来回切。
- 两种界面读写同一份数据，切换不迁移、不复制，切完还停在同一个 Bot。
- 第一次进轻松模式给一张一次性说明卡，之后不再弹。
- 轻松模式只跑在本机原生界面；网页模式仍只在专业模式下可选。

## 轻松模式（四个 Tab）

- **消息**：Bot 与群聊按最近活跃排一行，未读点、置顶、左滑不显示；点开就是对话。
- **伙伴**：Bot 名片网格，点开是资料卡——头像、名字、角色、它记得的事、现在能用的权限档位（只读）、发消息、删除（二次确认）。资料卡**不显示** token、模型名和原始记录。
- **发现**：现有功能的入口网格（会话、工作区、终端、手机操控、语音、桌宠、插件、技能、社区、主机与远程、引擎、模型渠道、全部设置、定时任务等），需要会话的入口在没有会话时置灰并提示。
- **我**：AI 对我的了解（记忆，可删）、外观、AI 服务、高级。

## 对话页（轻松外观）

- 顶栏只留头像、名字和更多；右侧的模型胶囊与详情键收起。
- 上下文满了以后新开的一段，用一条分隔线说明「上下文已满，从这里开始新的一段」，不再显示「更早的部分」。
- 出错时给一条柔和的提示和「重试」。
- 输入区去掉会话条与底部 footer，附件面板不带「本对话：权限/计划模式」。
- 空态给三句建议，点一下直接发。
- 列表行的状态优先级是「等你确认 > 正在输入 > 已完成」——和专业首页的顺序相反，因为轻松界面要先告诉用户有人等他回话。

## 已知边界

- 群聊暂未轻量化：消息列表里点开群，仍进现有的群页（含群目标胶囊）。
- 新文案暂时放在本地双语表里（`app/lib/ui/im/im_strings.dart`、`im_face_strings.dart`），等能跑 `flutter gen-l10n` 时迁到 `lib/l10n/parts/*.arb`。
- 段边界的「更早的 N 段」入口没有做：`chat` 的 cursor 本来就跨段，时间线是连续的。
