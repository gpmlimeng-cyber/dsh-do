## Coka 2.1.8（预览版）

这一版没有加我们自己的功能，做的是**把上游 dsh-go 从 1.0.11 追到 1.0.12**（`main` 到 `bb717f2a`，325 个提交、664 个文件）。合成后共改动 556 个文件、约 6.3 万行。

### 更新前请注意

- 这是预览版，不是正式版。App 内要在 `设置 › 更新` 里打开「包含预览版」才看得到它。
- 直接覆盖 2.1.7 就行，包名没变，对话、Bot、群、设置都在。
- 这版动的是底座，不是皮肤：界面外观和上一版一样，多出的是上游的功能。

### 上游这次带来的新东西

- **陪伴角色（companion）**：整套页面和外壳，带它自己的设置、对话流和状态。她的**人设可以改**（名字、设定、她怎么称呼你），**声音可以克隆**，还能在 Xiaomi MiMo、OpenAI、SiliconFlow、阿里几家之间选语音预设。
- **桌面小组件**和通知那边的配套改动（新的组件入口、语音插件）。
- **手机操控**那一大块修了很多：后台屏快照过期要刷新、旧任务的点击不再打到新任务上、横向手势方向、按键按下/抬起的配对、Shizuku/Sui 提供方不一致时不再假报就绪、超时任务的执行器和计时器不再串。
- **引擎与运行时**：插件安装输出的中文/emoji 跨块不再乱码、安全模式启用插件前先真解析 bundle、坏掉的 Agent 预设会显示实际原因、工作区索引坏了能走救援索引、重置失败不再报空成功。
- **远程与更新**：迟到的登出请求不再删掉新登录的凭据、中继连接不会互相顶替、多签名 APK 的更新预检不再误判。

### 合并时做的决定（会影响行为，写在前面）

- **图标还是 Coka 的**：上游仍用鲸鱼矢量（`ic_launcher_monochrome`、`ic_stat_dsh`、`glyph-mono.svg`），这些在我们的分支上早被手绘 PNG 取代，这次继续保持删除状态，不会被上游改回去。
- **上下文占比环的语义**：上游新加了「预估 token」。现在预估值为 0 就算真的 0%（刚开始新的一段），而**采样**为 0 仍算「还没测到」，环照旧隐藏，不会骗人说空了。两边的测试都保留、都过。
- **图片加载失败的占位**：保留我们的「点一下告诉你失败原因并重试」，同时接受上游加了无障碍标签、点开看大图的行为。
- **语言包**：我们的 34 条 + 上游 554 条，按 `parts/*.arb` 重新生成。另外有 **29 条字符串以前只写在生成出来的 `app_zh.arb` 里**（没进 parts），重新生成会把它们丢掉——这次已补回各自的 part（hub 1、bots 3、chat 4、shell 12、voice 9），含三个带参数的。

### 这一版修掉的问题

- **Bot 私聊和群聊的思考行，改成网页版那种**：以前它是消息外的一行灰字（「名字 · 思考中」），只在「这一轮最新一条正好是思考」的那几秒出现，一开口出字就没了。现在是消息体内那条可展开的过程行，和网页版、普通会话一致：跑到哪跟到哪，正文和工具行来了它也不走，点一下展开全文。群聊里同时去掉了合成的那条「名字 · 正在写」——两行说的是同一件事。
- **活动行不再叠第二层**：群里多人同时在跑时，输入区上方原来会多出一张「另外还有 N 位在跑」的卡片，浮在活动行上面；群头那行本来就写着谁在跑、已说几句，这条删掉。
- **群聊页、Bot 页抽屉里的「网页模式」键点了没反应（首次进入时最明显）**：那个键住在抽屉里，而这几页关抽屉会把整页拆掉，于是「关抽屉 → 切界面」的后半截经常落在页面已经没了的时刻，切不上去，重启之后时序变了才正常。现在改成：键只**同步投递一个「要切到网页」的请求**，真正的切换由首页来做——首页是唯一不会随页面消失的东西。切过去之后还会把压在首页上的原生页面（Bot 页、群页、详情页）收回到首页，不会再出现「切了但网页被挡住」。
- **上游合并留下的 4 条静态分析提示**：三个没用的导入、一个多余的判空调用，都清掉了。

### 已知问题

- **界面截图测试没重拍**：10 张 golden 还是旧像素，CI 上的截图检查是红的。静态分析这轮是 **0 error、4 warning**，4 条已在本版清掉。
- **排队标签仍未生效**：队列接上了，两个标签和三个动作没打通，气泡仍显示「发送中」。
- **群里机器人发的图片还是没有缩略图**：跟上游一致，只有「图片」两字。
- **引擎切后台会被停掉**：回来要重新拉起，7–10 秒不可用；不想停可以打开「后台保持引擎运行」。

### rc.12 起

- **群里 @成员 有颜色了**：成员名按那个人自己的颜色画，和网页版同一条规则——只认本群成员的名字、长名字优先、代码块和链接里的 `@` 不动、邮箱地址不算。这条也修掉了前几个提交留下的编译错误（群消息组件的依赖没导入等）。
- **群里自己发的图片能显示了**：根因是图片引用只带了 id，没带引擎读取所需的字节数和尺寸，引擎直接拒绝，界面就只剩一个灰色破图框。现在 host 把字节数、宽高一起发，历史分页、实时消息、回合回复三条路都补齐。
- **群成员消息的脚注和普通回复一致**：消息下面一行「39 秒 · 7 步 · 109K tokens ›」，数字由 host 按这一轮的工具调用数和成员 Session 的 token 用量差值记，点开直接打开该成员在本群的用量统计面板。旧 Host 只发耗时的话，这一行就只有耗时。
- **设置里新增**：消息布局（气泡/平铺）、气泡宽度、显示思考过程；「Bot」分组收纳团队/思考/语音/通知。

- **Bot 页的输入框和普通会话对齐了**：打字时输入框会像普通会话那样展开，模型选择器出现在输入框里、加号旁边，点开是和顶部一致的模型面板；选中的模型直接写回这个 Bot。

- **活动行点得开了**：群聊和 Bot 私聊里，输入框上方那条「正在跑」的行以前点了没反应（回调没接）；现在和普通会话一致，点开是这一轮的本轮轨迹，没有轮次时退到用量面板。

- **Bot 页顶栏不再重复显示模型**：模型选择器已经在输入框里了，顶栏那个去掉了，改动模型的入口只剩一处。

- **顶栏和内容之间不再有一条线**：顶栏那层半透明以前是「实心到底、最后 16dp 才淡出」，所以能看出一条边；现在只在状态栏那点高度保持实心，剩下的高度整段缓出，顶栏和文字区就在同一个渐变里衔接，看不出分界。所有顶栏共用这一处，普通会话、Bot 页、群聊、详情页一起变。

- **底部托板也无缝了**：输入区下面那层半透明原来只在顶部 14dp 淡出，现在按托板自身高度留一段长渐变（比例可调，上限 140dp），和顶栏是同一套做法，普通会话和 Bot/群聊都换上了。

- **「显示思考过程」「消息布局」「气泡宽度」点了没反应**：三个新设置写状态时都没被 `copyWith` 带上，所以拨了立刻回到旧值。修好后三项都生效。
- **消息布局与气泡宽度移进「Bot」分组**（原来在「外观」）。

- **群消息的气泡贴着头像，正文和成员名字左对齐**：气泡的左边距从 14 缩成 10，整块再往左让 10，于是有气泡时正文的落点和没有气泡时完全一样，不再比名字往里缩一截。

- **成员头像和输入框左边缘对齐**：消息行的左边距从 16 收到 12，和输入框外沿一致，成员头像、名字、气泡正文都落在同一条竖线上。

- **群消息的统计挪到成员行**：成员名、时间后面直接跟「17 秒 · 2 步 · 1.12M tokens ›」，点开还是用量面板；续行没有名字行，统计就留在气泡下面。

- **底部渐隐改成「整块渐变」**：托板多高就覆盖多高，顶边透明、底边实心，输入框和上面的活动行都在渐变里；以前是在托板上方另起一段，起点太靠上。
- **消息平铺只作用于 Bot**：自己发的消息永远是气泡，一眼能看出哪句是自己说的。

- **续行的统计并到首行**：同一位成员连着说几句时，只在第一行报一次这一轮的「耗时 · 步数 · tokens」，数字取这一段最后一行的（最完整的那个），续行不再各带一份。

- **底部只剩一层渐变**：输入框上方那条活动行不再自带玻璃卡片底（顶栏下面那块渐变直接透上来），底部不会再读成「两张卡片叠在一起」；输入框本身仍是白色圆角块。

- **底部两种状态分开**：模型还在想、还没动工具时，输入框上方是打字行（一句话 + 三个跳动的点）；开始跑工具、进入调研状态才换成活动行（在跑什么、多久）。判断依据是这一轮的活动类型：等待 / 思考 / 正文流 / 重试算「打字」，工具、确认、压缩算「活动」。

- **打字行对齐网页版**：现在是一张脸 + 「名字 · 状态…」 + 三个点 + 右边计时，具体是谁在写一眼能看出来；活动行仍是图标 + 在跑什么 + 计时。

- **打字行的短语用 App 自己的池子**：不再固定一句「思考中」，而是按状态从 App 的短语池里取（思考/等待/写作，另有深夜、周末、节日彩蛋），右边计时是自己走的。

- **打字行前面有成员头像了**：群聊显示正在写的那位成员，成员视图和 Bot 私聊显示这个 Bot，格式是「头像 + 名字 · 短语…」+ 计时，不再是光一句短语。

- **活动行恢复 App 的胶囊样式**：底部只有「思考」阶段是素净的打字行，开始跑工具后又回到 App 一贯的玻璃胶囊（在跑什么 + 计时，可点开），不再改成素文字。

- **底部文字从托板下面穿过去**：以前正文止于托板上沿（内容被切掉），现在正文铺到屏幕底、从渐变下面穿过去，末尾又留了托板高度，最后一条仍能滚到输入框上方看清。

- **活动胶囊有边了**：浅色页面上它原来的发丝线只有 8%，和白底糊成一片，看着像没有边框；现在描边提到 22%、0.8dp，胶囊边界能看清（普通会话同一个组件一起变）。

- **打字行和活动行是同一颗胶囊**：以前打字行是素的、活动行是胶囊，边框时有时无；现在两种状态都在同一颗胶囊里，只有内容变（打字时说谁在写，干活时说在跑什么）。胶囊描边也从 8% 提到 22%，浅色页面上能看清。

- **活动行说人话了**：手机操控/MCP 这类工具以前直接显示原始工具名（`screen`）和命令原文，现在翻成「看一眼手机屏幕」「点手机上的按钮」「在手机上打字」这类句子，原文不再往活动行上摆。
